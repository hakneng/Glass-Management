   - បង្ហាញតារាងសង្ខេបស្ថិតិស្វ័យប្រវត្តិ (និទ្ទេស A, B, C, D, E, F និង និទ្ទេសល្អ, ល្អបង្គួរ, មធ្យម, ខ្សោយ ដោយបែងចែកតាមភេទ) ព្រមទាំងកាលបរិច្ឆេទ និងហត្ថលេខានាយកសាលា & គ្រូបន្ទុកថ្នាក់។

6. **លទ្ធផលឆមាស និងប្រចាំឆ្នាំ (Semester & Annual Summary Table):**

     - មធ្យមភាគឆមាសទី១ = (មធ្យមភាគខែ + ពិន្ទុប្រឡងឆមាសទី១) / ២
     - មធ្យមភាគឆមាសទី២ = (មធ្យមភាគខែ + ពិន្ទុប្រឡងឆមាសទី២) / ២
     - មធ្យមភាគប្រចាំឆ្នាំ = (មធ្យមភាគឆមាសទី១ + មធ្យមភាគឆមាសទី២) / ២
   - ចេញមូលវិចារគ្រូបន្ទុកថ្នាក់ស្វ័យប្រវត្តិ៖
     - មធ្យមភាគ >= ២៥.០០ : **"មានសិទ្ធិប្រឡងសញ្ញាបត្រទុតិយភូមិ"**
     - មធ្យមភាគ < ២៥.០០ : **"ត្រូវប្រឡងឡើងថ្នាក់"** / **"ត្រូវរៀនត្រួតថ្នាក់"**

## 💻 របៀបបើកដំណើរការកម្មវិធី (How to Run)

លោកអ្នកអាចបើកដំណើរការកម្មវិធីបានយ៉ាងងាយស្រួលតាមវិធីណាមួយដូចខាងក្រោម៖

### វិធីទី១ (រហ័សបំផុត - One Click):
ចុចទ្វេដង (Double Click) លើឯកសារ **`start.bat`** ក្នុងថត `Glass management`។  
វានឹងបើក Browser ឡើងលើអាសយដ្ឋាន `http://localhost:3000` ដោយស្វ័យប្រវត្តិ។

### វិធីទី២ (បើកតាម Browser ដោយផ្ទាល់):
ចុចទ្វេដងលើឯកសារ **`index.html`** ដើម្បីបើកជាមួយ Google Chrome, Microsoft Edge ឬ Firefox ដោយមិនចាំបាច់មាន Server ក៏ដំណើរការបានពេញលេញដែរ។

### វិធីទី៣ (តាមរយៈ Node.js Command Line):
```powershell
node server.js
```
រួចបើក Browser ចូលទៅកាន់: `http://localhost:3000`
