ជម្រើសទី ១៖ ថត «01_ឯកសារកែប្រែថ្មី_Modified_Files_Only»
-------------------------------------------------------------
សម្រាប់លោកអ្នកដែលចង់ Upload តែ File ណាដែលទើបតែកែប្រែថ្មីៗទៅជំនួស (Replace) លើ GitHub ឬ Server៖
  - version.json       (ដំឡើងទៅ v20.1 ផ្លូវការ)
  - index.html         (មានផ្ទាំងចាក់សោរ និងប៊ូតុងកូនសោរលើ Topbar)
  - Update_Package.zip (កញ្ចប់ដំឡើងអាប់ដេតថ្មី ៨៦០ KB)
  - js/app.js          (កូដមុខងារចាក់សោរថ្នាក់, លុបបុព្វបទ «ក.», Excel 2 Sheets...)
  - js/storage.js      (ប្រព័ន្ធរក្សាទុកទិន្នន័យចាក់សោរថ្នាក់)

👉 របៀបធ្វើលើ GitHub:
  1. បើក Browser ចូលទៅ Repo របស់លោកអ្នក: https://github.com/hakneng/Glass-Management
  2. ចុច «Add file» -> «Upload files»
  3. ទាញ (Drag & Drop) ឯកសារ version.json, index.html, Update_Package.zip ចូល
  4. ចុចចូល Folder «js/» រួច Upload ឯកសារ app.js និង storage.js ចូល
  5. ចុចប៊ូតុងពណ៌បៃតង «Commit changes» ជាការស្រេច!
